# StoerFisch-Docs

Auto-generated [Doxygen](https://www.doxygen.nl/) documentation for the [StoerFisch](https://github.com/VusionGroup/StoerFisch) project.

Do not edit files in `html/` or `man/` by hand, they are overwritten by the `docs.yml` workflow in the `StoerFisch` repo on every push to its `main` branch. To change the content, edit the source code's doc comments (or the `Doxyfile`) in that repo instead.

Browse the docs by opening [`html/index.html`](html/index.html).
