# StoerFisch-Docs

Auto-generated [Doxygen](https://www.doxygen.nl/) documentation for the [StoerFisch](https://github.com/VusionGroup/StoerFisch) project.

Do not edit files in `docs/` by hand, they are overwritten by the `docs.yml` workflow in the `StoerFisch` repo on every push to its `main` branch. To change the content, edit the source code's doc comments (or the `Doxyfile`) in that repo instead.

Published via GitHub Pages at https://vusiongroup.github.io/StoerFisch-Docs/, or browse locally by opening [`docs/index.html`](docs/index.html).
