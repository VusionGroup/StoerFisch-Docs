Detailed Description

In-Process-Kommandopfad fuer ROD_FAKE=1.

Validiert wie der Core (zustandslose Checks) und reicht angenommene
Kommandos an die Fake-Telemetrie weiter, damit applied_command_seq
nachzieht.
