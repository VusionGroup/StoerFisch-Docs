Detailed Description

Sendebetrieb (Jamming/Replay) + IQ-Aufnahme.

Der springende Punkt ist HALBDUPLEX: sobald gesendet wird, steht der RX-Betrieb
komplett -- keine Frames, keine Telemetrie, bis STOP_TRANSMIT. Diese Tests
sichern, dass der Fake das genauso abbildet (sonst liefe die Auswertung gegen ein
zu freundliches Modell) und dass Senden nur scharfgeschaltet moeglich ist.
