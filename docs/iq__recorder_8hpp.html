Detailed Description

Zeichnet rohe IQ-Samples (interleaved int8, HackRF-Format) in eine .cs8-Datei auf, mit einer .meta-Sidecar für Sample-Rate/Frequenz.

Der Callback kopiert die Bytes nur in den Ring (wait-free) und kehrt sofort zurück. Ein separater Thread leert den Ring auf die Platte. Läuft die Platte kurz voll oder hakt, füllt sich der Ring, ist er ganz voll, werden Samples VERWORFEN (und gezählt), aber der RX-Stream bricht nie zusammen.

DATEIFORMAT: <name>.cs8 rohe interleaved int8 I/Q (2 Byte pro komplexem Sample) <name>.cs8.meta JSON: sample_rate_hz, center_freq_hz, start_unix_ns, sample_count, dropped_samples.
