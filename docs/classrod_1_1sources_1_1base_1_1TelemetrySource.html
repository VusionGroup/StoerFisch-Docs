Detailed Description

Single-Consumer-Quelle fuer Telemetrie-Records.

``poll()`` liefert bereits serialisierte, JSON-taugliche dicts (siehe
hub/serialize.py) -- je mit einem ``kind``-Diskriminator. Das haelt Hub und
Fake-Quelle auf demselben Schema.
