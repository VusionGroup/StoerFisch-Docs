Detailed Description

Synthetische ``TelemetrySource`` + Kommando-Senke fuer den Fake-Betrieb.

Haelt einen kleinen Simulationszustand (Regelkreis an/aus, Aktuator, Retune,
Sendebetrieb) und erzeugt daraus Records aller Typen. ``apply_command`` (vom
Fake-Transport aufgerufen) veraendert diesen Zustand -- so wird der komplette
Steuer->Wirkung-Weg (bis Ack-Ebene 3) ohne Core testbar.
