Detailed Description

Ein einzelner Slot im Ringpuffer: fixe Größe, versioniert, selbstbeschreibend über type.

Layout ist absichtlich flach und ohne Zeiger/virtuelle Funktionen, damit es 1:1 als Bytes in Shared Memory liegen und in Python per numpy-structured-dtype ausgelesen werden kann (siehe python/telemetry_layout.py).
