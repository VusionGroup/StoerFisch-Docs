Detailed Description

RAII-Wrapper um die HackRF-Hardware (libhackrf).

Kapselt Öffnen/Konfigurieren/Streamen eines HackRF One und reicht die empfangenen IQ-Samples an einen vom Aufrufer gesetzten Callback weiter. Entspricht [1.2.2] "Kanalblockade via HackRF SDK" im PSP.

IQ-FORMAT: HackRF liefert interleaved 8-bit-signed I/Q (int8_t-Paare). Der Wrapper wandelt sie in normalisierte float-Paare im Bereich [-1, 1) um (Teilung durch 128), damit die nachgelagerte FFT mit float rechnen kann.

GAIN-BEREICHE (aus der HackRF-One-Doku)

  • LNA (RX IF) : 0..40 dB in 8-dB-Schritten -> hackrf_set_lna_gain
  • VGA (RX BB) : 0..62 dB in 2-dB-Schritten -> hackrf_set_vga_gain
  • TX VGA (IF) : 0..47 dB in 1-dB-Schritten -> hackrf_set_txvga_gain
  • RF-Amp : 0 / ~11 dB an/aus -> hackrf_set_amp_enable
