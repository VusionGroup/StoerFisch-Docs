Detailed Description

Transport für den Kommandopfad Rod (Python) -> Core (C++), über einen Unix Domain Socket.

DIE DREI ACK-EBENEN (siehe command.hpp für Details): Dieser Kanal liefert AUSSCHLIESSLICH Ebene 2 (validiert). Ebene 3 (angewendet) läuft über ActuatorStatePayload::applied_command_seq im TelemetryRing, ganz bewusst NICHT über diesen Kanal, damit der CommandChannel-Thread nie auf den RX-Thread warten muss.

EIN CLIENT ZUR ZEIT: Wie der TelemetryRing für genau einen Producer/Consumer ausgelegt ist, ist dieser Kanal für genau eine Rod-Verbindung ausgelegt. Ein zweiter Verbindungsversuch wartet in accept(), bis die erste Verbindung endet. Für Multi-Client-Betrieb bräuchte es echte Nebenläufigkeit pro Verbindung.

EIGENER THREAD, NICHT TEIL DES HOUSEKEEPING-THREADS
