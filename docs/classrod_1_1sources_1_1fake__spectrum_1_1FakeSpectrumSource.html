Detailed Description

Synthetische ``SpectrumSource``: liefert plausible dB-Frames ohne Core/HackRF.

Erfuellt dasselbe Protokoll wie ``ShmSpectralSource``, damit Hub/API nicht
unterscheiden muessen. Rauschboden + zwei stehende Traeger + optionaler,
an die Fake-Telemetrie gekoppelter Stoerer; das Fenster folgt Retunes.

◆ read_latest()

SpectrumFrame | None rod.sources.fake_spectrum.FakeSpectrumSource.read_latest (   self,
int  max_drain 
) 
Erzeugt den naechsten synthetischen Frame.

Folgt zuerst der SDR-Sonde (Retune uebernehmen); pausiert RX, kommt
``None`` (kein Frame). Sonst: Rauschboden + zwei bewegte Traeger, und
falls der Jammer an ist, ein dritter Peak an der Aktuator-Frequenz.

Args:
    max_drain: aus Protokollgruenden vorhanden; hier ohne Wirkung, weil
        der Fake immer nur genau den aktuellen Frame erzeugt.
Returns:
    Ein ``SpectrumFrame`` oder ``None``, wenn RX gerade pausiert.
