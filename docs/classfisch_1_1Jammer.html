Detailed Description

Erzeugt ein Störsignal zum aktiven Blockieren eines Kanals.

Zwei Muster:

  • CarrierWave: ein Dauerträger
  • Noise: bandbreitenfüllendes Rauschen.

Das Signal ist endlos – fill() liefert immer den ganzen Puffer. Gestoppt wird über stopTx() vom main_loop.
