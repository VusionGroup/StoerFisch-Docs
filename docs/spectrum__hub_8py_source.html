1"""SpectrumHub: zentraler Drain des Spektral-Rings + Quantisierung.
2
3Wie beim Telemetrie-Ring gilt Single-Consumer: nur EIN Task liest den Ring.
4Er bereitet bei ``fps`` den neuesten Frame als binaeres Wire-Paket vor
5(float64 center + uint8-Bins); die einzelnen Spectrum-WebSockets ziehen (PULL)
6nur noch das jeweils aktuelle Paket. So haengt die Ring-Leserate nicht an der
7Zahl der Browser.
8
9``spectrum_meta`` wird aus ZWEI Quellen zusammengesetzt: fft_size, center und
10die Qualitaetszaehler kommen aus dem Ring; sample_rate kommt aus dem Kontroll-
11pfad (der Core fuehrt sie nicht im Ring). Ein Callable liefert die aktuelle
12sample_rate, damit eine Aenderung im SdrPanel sofort in die Skalierung greift.
13"""

97 async def _run(self) -> None:
98 """Drain-Schleife: neuesten Frame holen (aeltere ueberspringen), DC notchen,
99 quantisieren, als Wire-Paket ablegen und die Sequenz erhoehen."""
100 while True:
101 frame = self._source.read_latest(self._max_drain)
102 if frame is not None:
103 bins = notch_dc(frame.bins, self._dc_notch)
104 quant = quantize_db(bins, self._db_floor, self._db_ceil)
105 self._latest_payload = struct.pack("<d", frame.center_freq_hz) + quant.tobytes()
106 self._center_freq_hz = frame.center_freq_hz
107 self._latest_seq += 1
108 await asyncio.sleep(self._interval)
