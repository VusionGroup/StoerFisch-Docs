Detailed Description

Loest einen HW-Retune im Core aus (SET_SAMPLE_RATE / SET_CENTER_FREQ).

Die Grenzen spiegeln die Core-Validierung; ausserhalb antwortet der Core mit
INVALID_SAMPLE_RATE / INVALID_FREQUENCY. Wir lehnen hier schon mit 422 ab,
damit ein Tippfehler im UI keinen Retune anstoesst.
