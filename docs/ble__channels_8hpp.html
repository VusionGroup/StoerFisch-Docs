Detailed Description

Zentrale Umrechnung zwischen BLE-Kanalnummer, Frequenz-Index und Frequenz. EINE Quelle der Wahrheit für alle Module.

DER KERNPUNKT, DER LEICHT FALSCH GEMACHT WIRD: BLE hat 40 Kanäle, 2 MHz Abstand, von 2402 bis 2480 MHz. Die physikalische Reihenfolge (der "Frequenz-Index" k: f = 2402 + 2k MHz) ist NICHT dieselbe wie die BLE-Kanalnummer. Die drei Advertising-Kanäle 37/38/39 sitzen physikalisch VERSTREUT zwischen den Data-Kanälen:

Frequenz Index k BLE-Kanal Typ 2402 MHz 0 37 Advertising 2404 MHz 1 0 Data 2406 MHz 2 1 Data ... ... ... Data 2424 MHz 11 10 Data 2426 MHz 12 38 Advertising <- mitten drin! 2428 MHz 13 11 Data ... ... ... Data 2478 MHz 38 36 Data 2480 MHz 39 39 Advertising

Wer einfach (f - 2402) / 2 rechnet, bekommt den FREQUENZ-INDEX und nennt ihn fälschlich BLE-Kanal. Für einen BLE-Störsender ist aber die logische Kanalnummer relevant ("Data-Kanal 5 ist belegt"), nicht die Frequenzposition.

Quelle: STMicroelectronics PM0271 Rev 13, S.5; Bluetooth Core Spec (f_c = 2402 + 2k MHz, k = Frequenz-Index). Mehrfach gegengeprüft.
