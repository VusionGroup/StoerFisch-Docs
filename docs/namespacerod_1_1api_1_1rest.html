Detailed Description

REST-API: Status abfragen und Steuerkommandos absetzen.

Die POST-Routen sind duenne Huellen um den Controller. Fehler aus dem
Kommandopfad landen auf HTTP: ein abgelehntes Kommando gibt 409, ein toter
Transport 503.
