Detailed Description

REST-API: Status abfragen und Steuerkommandos absetzen.

Die POST-Routen sind duenne Huellen um den Controller. Fehler des Kommando-
pfads werden auf HTTP gemappt: ein abgelehntes Kommando (CommandError) ->
409, ein toter Transport (CommandTransportError) -> 503.

FastAPI-Dependency: laesst nur den aktuellen Schreibrecht-Inhaber durch.

Liest die owner-id aus dem ``X-Owner``-Header und vergleicht sie mit dem
Writer der Lease. Zuschauer (kein Schreibrecht) bekommen 403 -- jede
schreibende Route ist damit serverseitig gesperrt, nicht nur im UI. Gibt die
owner-id zurueck, damit die Route sie ohne erneutes Auslesen nutzen kann.
