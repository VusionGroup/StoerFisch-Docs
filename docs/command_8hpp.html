Detailed Description

Wire-Schema des Kommandopfads Rod (Python) -> Core (C++).

DIE DREI EBENEN VON "ACK"

  1. Empfangen -> implizit, sobald eine CommandResponse zurückkommt.
  2. Validiert -> CommandResponse.status. Das leistet dieser Header (validateCommand()). Läuft im Housekeeping-Thread, fasst den zeitkritischen RX-Thread NICHT an.
  3. Angewendet -> NICHT über diesen Pfad! Der RX-Thread schreibt die command_seq des zuletzt übernommenen Kommandos in ActuatorStatePayload::applied_command_seq (#6). Roman sieht die Wirkung also im Telemetrie-Strom.

Alle Kommandos sind ABSOLUT, nie relativ. SetTxGain(20 dB), nicht GainUp(+3 dB).
