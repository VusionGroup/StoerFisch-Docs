Detailed Description

Telemetrie-Records aus numpy in JSON-taugliche dicts.

Jeder Record bekommt einen kind-String, auf den der Browser matcht, dazu die
typunabhaengigen Felder sequence und timestamp_ns. Zwei Dinge erledigen wir
gleich hier, weil sie im Browser nichts verloren haben: die uint64-Belegungs-
maske wird zu bool[40] aufgefaltet und die reserved-Padding-Felder fliegen raus.
