Detailed Description

Lock-freie SPSC-Warteschlange für validierte Kommandos zwischen CommandChannel (Producer) und dem Controller/RX-Thread (Consumer).

Zweck: Der CommandChannel validiert Kommandos in seinem eigenen Thread (billig, darf blockieren) und legt nur GÜLTIGE Kommandos hier ab. Der RX-Thread holt sie nicht-blockierend ab, wann immer sein Zyklus das zulässt, er wartet nie auf den CommandChannel!
